# Task 2 - Exploratory Data Analysis (EDA)

## Objective

The objective of this task is to understand the dataset using descriptive statistics and data visualizations.

## Dataset

Titanic dataset.

The dataset contains information about 891 passengers and 15 features.

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Plotly

## EDA Performed

The following analysis was performed:

1. Displayed the first five rows of the dataset.
2. Checked dataset information and data types.
3. Generated summary statistics.
4. Checked missing values.
5. Checked the shape of the dataset.
6. Created a histogram for passenger age.
7. Created boxplots for age and fare.
8. Created a pairplot to study relationships between numerical features.
9. Created a correlation matrix.
10. Created a scatter plot showing the relationship between age and fare.

## Key Observations

- The dataset contains 891 rows and 15 columns.
- The average passenger age is approximately 29.7 years.
- There are 177 missing values in the age column.
- There are 688 missing values in the deck column.
- Boxplots help identify possible outliers in age and fare.
- The correlation matrix helps understand relationships between numerical variables.
- The scatter plot shows the relationship between passenger age and fare.

## Conclusion

Exploratory Data Analysis helped understand the structure, distribution, missing values, relationships, and possible patterns in the Titanic dataset using statistics and visualizations.
